# 🌌 Архитектор Реальности (Telegram Bot на Rust)

Высокопроизводительный асинхронный Telegram-бот на языке **Rust** (`teloxide` + `tokio` + `sqlx`), предоставляющий эзотерические сервисы: Карты Таро с толкованием, Астрологические расчеты, Конструктор намерений и древнюю игру самопознания «Лила».

---

## 🔮 Основные модули и функционал

1. **🃏 Карманный таролог**:
   - **Карта дня**: Случайный Старший Аркан Таро с HD-изображением и подробной трактовкой на текущий день.
   - **Глубокий расклад**: Персональный разбор ситуации и ответ на сакральный вопрос пользователя.

2. **🌌 Астрологический свод**:
   - **Карта Личности**: Архетип, баланс стихий, точки роста и ресурсы.
   - **Астрофон дня**: Персональный планетарный фон.
   - **Вектор Года**: Ежемесячный календарь взлётов и периодов замедления.
   - **Матрица Реализации**: Анализ сильных и теневых сторон, финансовые каналы.
   - **Совместимость**: Разбор синастрии по двум датам рождения.

3. **⚙️ Конструктор реальности**:
   - Пошаговая манифестация целей и квантовое заякорение через цвет и эмоциональное состояние.

4. **🎲 Игра Лила**:
   - Интерактивная игра самопознания на 72 клетки с использованием Telegram Dice API (`sendDice`).

---

## 🛠️ Стек технологий

- **Язык**: Rust (Edition 2021)
- **Фреймворк бота**: `teloxide 0.13`
- **Асинхронность**: `tokio`
- **База данных**: `sqlx` (SQLite)
- **Логирование**: `tracing` + `tracing-subscriber`

## 🚀 Установка и запуск

### 1. Клонирование репозитория
```bash
git clone https://github.com/ВАШ_АККАУНТ/reality_architect_bot.git
cd reality_architect_bot
```

### 2. Настройка переменных окружения
Создайте файл `.env` на основе примера:
```bash
cp .env.example .env
```
Заполните `.env`:
```ini
TELOXIDE_TOKEN=ваш_токен_от_BotFather
DATABASE_URL=sqlite://bot.db?mode=rwc
ADMIN_TELEGRAM_ID=ваш_telegram_id
RUST_LOG=info
```

### 3. Запуск бота
```bash
cargo run
```
Для сборки релизной оптимизированной версии:
```bash
cargo build --release
./target/release/telegram_bot
```
